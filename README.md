# 🦇 Batcave Control Panel

Um dashboard web responsivo que simula o centro de comando da Batcaverna do Batman, com visual de alta tecnologia, tema escuro e efeitos neon azul e verde-radar.

## ✨ Características

- **Design Responsivo**: Adapta-se perfeitamente a diferentes tamanhos de tela
- **Tema Escuro**: Interface com cores escuras e efeitos neon
- **Efeitos Visuais**: Animações sutis, radar scans e efeitos de hover
- **Interatividade**: Botões funcionais, notificações e atualizações em tempo real
- **Atalhos de Teclado**: Controles rápidos para todas as funcionalidades
- **Fontes Futurísticas**: Orbitron e Rajdhani para um visual high-tech

## 🎮 Funcionalidades

### 🎥 Painel de Vigilância
- Grid de 4 câmeras com efeitos de radar
- Controles de play/pause/expandir
- Indicadores de status em tempo real
- Animações de sweep do radar

### 🚗 Controles Principais
- **Status dos Veículos**: Batmobile, Batwing e Bat-Pod
- **Sistemas de Armas**: Grappling Hook, Electroshock, Smoke Bombs, Armor Plating
- **Comunicações**: Police Scanner, Bat-Signal, Satellite Link

### 📊 Análise de Dados
- **Casos Ativos**: Sistema de prioridades (Alta, Média, Baixa)
- **Estatísticas de Gotham**: Taxa de crime, tempo de resposta, etc.
- **Monitor do Sistema**: CPU, Memória e Rede em tempo real

## ⌨️ Atalhos de Teclado

| Tecla | Função |
|-------|--------|
| `1` | Ativar Grappling Hook |
| `2` | Ativar Electroshock |
| `3` | Ativar Smoke Bombs |
| `4` | Ativar Armor Plating |
| `S` | Alternar Vigilância |
| `R` | Atualizar Dados |

## 🎨 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e moderna
- **CSS3**: 
  - Grid e Flexbox para layout responsivo
  - CSS Variables para tema consistente
  - Animações e transições suaves
  - Media queries para responsividade
- **JavaScript ES6+**:
  - Classes para organização do código
  - Event listeners para interatividade
  - Timers para atualizações em tempo real
  - Notificações dinâmicas

## 🚀 Como Usar

1. **Abra o arquivo `index.html`** em qualquer navegador moderno
2. **Explore os painéis** clicando nos diferentes elementos
3. **Use os atalhos de teclado** para controle rápido
4. **Observe as atualizações** em tempo real dos sistemas

## 📱 Responsividade

O dashboard é totalmente responsivo e se adapta a:

- **Desktop**: Layout em 3 colunas (1200px+)
- **Tablet**: Layout em coluna única com grid adaptado (768px-1199px)
- **Mobile**: Layout otimizado para telas pequenas (<768px)

## 🎯 Efeitos Visuais

- **Neon Glow**: Bordas e elementos com brilho neon
- **Radar Animation**: Efeito de sweep circular nas câmeras
- **Pulse Effects**: Indicadores de status pulsantes
- **Hover Effects**: Interações visuais ao passar o mouse
- **Mouse Trail**: Rastro sutil do cursor para efeito high-tech
- **Background Shift**: Mudança sutil de cor de fundo

## 🔧 Personalização

O dashboard usa CSS Variables que podem ser facilmente modificadas:

```css
:root {
    --neon-blue: #00ffff;    /* Azul neon principal */
    --neon-green: #00ff41;   /* Verde radar */
    --primary-bg: #0a0a0a;   /* Fundo principal */
    --panel-bg: #0f0f0f;     /* Fundo dos painéis */
}
```
